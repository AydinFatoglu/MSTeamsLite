# MSTeamsLite


A lightweight Microsoft Teams launcher designed for corporate VDI environments.
Instead of installing the full Teams client, this tool opens Teams directly inside
a native application window — keeping things simple, fast, and easy to deploy.

---

## What it does

- Opens Microsoft Teams in a clean, standalone window
- Remembers your login session — no need to sign in every time
- Handles microphone, camera, and speaker permissions automatically
- Minimizes to the system tray when closed — stays out of your way
- Restore it anytime from the tray with a double-click or right-click menu
- Shows a clear error message if a required component is missing on the system
